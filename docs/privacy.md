# 隐私与媒体处理

## 信任边界

前端只负责预览和提交隐私矩形。所有公开发布的媒体必须由 Node.js API/Worker 使用服务端 Sharp 管线生成。客户端上传的“已模糊图片”仍会重新处理，不能直接进入公开桶。

## 处理步骤

1. API 校验用户、文件类型、大小和配额。
2. API 返回短期签名 URL，浏览器将原图上传到私有 `map-quarantine` 桶。
3. `/media/uploads/:id/complete` 校验对象确实存在且大小一致。
4. Worker 从隔离桶读取原图。
5. 如果启用 ClamAV，先执行 `INSTREAM` 恶意文件扫描。
6. Sharp 按 EXIF 方向旋转图片，并在重新编码时移除 EXIF/GPS 等元数据。
7. Worker 合并用户矩形和可选检测器返回的敏感区域。
8. 服务端对区域进行安全边距扩展和模糊。
9. Worker 重新编码 WebP 并生成缩略图、SHA-256 和感知哈希。
10. 没有自动检测器时，处理结果停留在私有桶并标记 `manual_review`。
11. 审核员通过 10 分钟签名 URL查看私有处理结果并确认隐私。
12. 只有确认后，处理图和缩略图才复制到公开桶并标记 `ready`。
13. 原图默认在 24 小时后由维护任务删除；失败媒体最多保留 7 天。

## 数据要求

- 原始文件对象键不可预测，隔离桶不允许匿名读取。
- 公开桶只允许已经过隐私确认的派生图。
- 日志中不得记录原图 URL、访问令牌、密码或完整个人信息。
- 默认不采集用户定位轨迹；浏览器定位必须由用户主动触发。
- 私人住宅内部、受限区域和实时人员位置不属于 V1 允许内容。
- 删除媒体时同时清理隔离原图、服务端处理图和公开派生图。

## 取证与水印

处理图和删除操作都会生成 Ed25519 签名的可验证凭证，存于 `media_credentials`：

- **处理凭证（`processed`）**：Worker 完成隐私处理后与媒体状态在同一事务签发，声明包含处理图 SHA-256、感知哈希、尺寸、处理时间和水印指纹。没有凭证的处理图不会进入公开流程。
- **删除凭证（`deleted`）**：维护任务在隔离原图、处理图和公开派生图全部从对象存储清除后签发，声明包含删除时间和清除范围（`all_objects`）。签发失败时该行保持待清理状态，下个维护周期重试；每种类型每个媒体只签发一次，重试幂等。
- **不可见水印**：处理图在最终 WebP 编码前嵌入 64 位媒体指纹（`HMAC(水印密钥, mediaId)`），采用 8x8 亮度块均值量化扩频，可承受 WebP 重编码和局部模糊；单像素改动不超过 ±10，肉眼不可见。水印密钥由 `MEDIA_SIGNING_KEK` 派生，不单独配置。取证核查使用 `pnpm --filter @map/worker forensics:extract <图片>` 提取指纹并反查处理凭证。
- **密钥轮换**：签名私钥用 `MEDIA_SIGNING_KEK` 派生的 AES-256-GCM 密钥加密后存于 `media_signing_keys`。`pnpm --filter @map/db forensics:rotate` 在事务中把当前密钥标记为 `retired` 并生成新密钥；retired 公钥永久保留，校验按凭证中的 `kid` 选钥，因此轮换后旧凭证仍可校验。
- **公开边界**：`/api/v1/forensics/credentials/:id` 和 `/api/v1/forensics/keys` 是公开地址，只返回白名单声明和公钥，不包含隔离桶键、原图哈希、文件名或所有者信息，无法用于定位或还原原图。
