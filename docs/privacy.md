# 隐私与媒体处理

## 信任边界

前端只负责预览和提交隐私矩形。所有公开发布的媒体必须由 Node.js API/Worker 使用服务端 Sharp 管线生成。客户端上传的“已模糊图片”仍会重新处理，不能直接进入公开桶。

## 处理步骤

1. API 校验用户、文件类型、大小和配额。
2. API 返回短期签名 URL，浏览器将原图上传到私有 `map-quarantine` 桶。
3. `/media/uploads/:id/complete` 校验对象确实存在且大小一致。
4. Worker 从隔离桶读取原图。
5. 如果启用 ClamAV，先执行 `INSTREAM` 恶意文件扫描。
6. Sharp 按 EXIF 方向旋转图片，并在重新编码时移除 EXIF/GPS 等元数据。
7. Worker 合并用户矩形和可选检测器返回的敏感区域。
8. 服务端对区域进行安全边距扩展和模糊。
9. Worker 重新编码 WebP 并生成缩略图、SHA-256 和感知哈希。
10. Worker 在处理图与缩略图嵌入隐形水印，按处理后字节派生密封公开地址，并签发可验证的处理凭证（见[媒体取证与水印](forensics.md)）。
11. 没有自动检测器时，处理结果停留在私有桶并标记 `manual_review`。
12. 审核员通过 10 分钟签名 URL查看私有处理结果并确认隐私。
13. 只有确认后，加水印的处理图和缩略图才复制到密封键名的公开桶位置并标记 `ready`。
14. 原图默认在 24 小时后由维护任务删除；失败媒体最多保留 7 天。
15. 删除媒体时签发可验证删除凭证，并同时清理隔离原图、服务端处理图和公开派生图。

## 数据要求

- 原始文件对象键不可预测，隔离桶不允许匿名读取。
- 公开桶只允许已经过隐私确认的派生图；公开键名由服务端密钥派生，不可由 media id 或原图哈希枚举。
- 凭证只记录原图的加盐承诺，原图哈希本身不出现在任何凭证或公开数据中。
- 日志中不得记录原图 URL、访问令牌、密码或完整个人信息。
- 默认不采集用户定位轨迹；浏览器定位必须由用户主动触发。
- 私人住宅内部、受限区域和实时人员位置不属于 V1 允许内容。
- 删除媒体时同时清理隔离原图、服务端处理图和公开派生图。
